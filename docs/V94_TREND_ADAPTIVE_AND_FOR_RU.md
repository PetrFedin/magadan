# V9.4 — Тренд-адаптивная климатология и FOR из открытой натурной статистики

Дата: 2026-11-16. Продолжение [V9.3](V93_EMOS_CALIBRATION_RU.md). Два направления
углубления, оба — без внешних ключей и без закрытых данных:

1. **Тренд-адаптивная климатология** — прямой ответ на диагноз V9.3: дефицит
   покрытия структурный (окно отстаёт от уровня на нестационарном ряде), и
   дисперсионная постобработка (EMOS) его не закрывает. Переносим уровень

2. **FOR для TurbineReliability** — опора на опубликованную натурную

## 1. Тренд-адаптивная климатология (`server/hydro_api/trend_adaptive_v9.py`)

Модель (лог-шкала, окно 20 лет строго < Y):

```
наклон:  Theil–Sen по парам лет окна; ДИ 95% — Sen (1968) через Var(S) Кендалла
уровень: b0 = медиана(logQ_i − b1·(y_i − ȳ));  level_Y = b0 + b1·(Y − ȳ)
ансамбль: смесь N(level_Y + a_i, v), a_i — аномалии окна,
          v = (se(b1)·(Y − ȳ))² — инфляция от неопределённости переноса тренда
выход: 20 равновероятных квантилей смеси (бисекция, детерминированно)
```

Ключевое отличие от «детрендированной климатологии»: дисперсия растёт с
расстоянием переноса за центр окна — именно это и требуется для покрытия на
нестационарном ряде.

## 3. Честное чтение

1. **Гипотеза V9.3 подтверждена**: структурная поправка уровня (тренд) даёт
   покрытие лучше, чем постобработка дисперсии (EMOS), при той же цене по
   остроте: cov80 0,673 против 0,628 при CRPS −3% в обоих случаях. Дефицит был
   прежде всего в положении, а не в ширине.
2. **До номинала всё равно не дотягивает**: 0,673 против 0,80 (и 0,823 против
   0,95). Остаток — нетрендовая нестационарность и межгодовая изменчивость
   режима; следующий шаг неизменен: физический драйвер притока (degree-day
   snowmelt V9.1 под ERA5-Land, нужен CDS-ключ владельца).
3. **Двойная коррекция вредна** (отрицательный результат): EMOS поверх
   тренд-ансамбля ухудшает и CRPS (−9,3% к сырой), и покрытие (0,619 < 0,673):
   калибровка по CRPS сжимает и без того корректно перенесённое распределение.
   EMOS остаётся слоем для ансамбля БЕЗ тренд-переноса, не поверх него.
4. Наклоны окна зашумлены (средний +3,9%/год в лог-шкале; разброс по месяцам
   велик, вклад маловодных зимних месяцев доминирует в относительной шкале) —
   согласуется по знаку с опубликованным ростом зимнего базового стока в
   криолитозоне, но величины по одному створу не обобщаются.
5. Зрелость HydroForecast **не повышается** (остаётся 3): физики притока в
   модели по-прежнему нет. `production_ready=False`, HOLD — без изменений.

## 4. FOR из открытой статистики (`server/hydro_api/forced_outage_v9.py`)

Формулы — отраслевые стандарты по опубликованным первоисточникам:

- IEEE Std 762 / NERC GADS DRI (Appendix F): `FOR = FOH/(FOH+SH+Sync+Pmp)`,
  EFOR с эквивалентными часами дерейтингов;
- PJM Manual 22: `EFORd = (f·FOH + fp·EFDH)/(SH + f·FOH)`,
  f-фактор спроса `f = (1/r + 1/T)/(1/r + 1/T + 1/D)`;
- PJM Manual 22 (immature unit): стягивание малой истории к классовому
  среднему `EEFORd = (n·hist + (5−n)·class)/5` — отраслевой приём работы с
  малым числом лет наблюдений;
- двухсостоятельная модель `μ=(1−p)·C`, `σ²=(1−p)·p·C²`; биномиальная
  надёжность станции из n агрегатов (ср. русскую практику Kв = ω·T).

Опорные данные: `data/reference/hydro_for_open_stats.json`
(класс OPEN-PUBLISHED-REFERENCE, каждое число со source_ref):

| Источник | Значения |
|---|---|
| NERC GADS 2008–2012, класс Hydro | FOR 5,79%, EFOR 5,99%, EFORd 5,43%, EAF 84,61% |
| IEEE 4500838 (гидроагрегаты Северо-Запада США) | общий коэффициент простоя 0,723% |
| Нормативная практика ВГЭК (РФ) | p_агрегата ≈ 0,999 в биномиальной модели |

Ограничение зафиксировано явно: классовая статистика GADS — североамериканский
флот; перенос на Колымский каскад допустим только как априорный класс для
стягивания. Натурная статистика журналов ГЭС — HOLD.

Зрелость TurbineReliability: **2 → 3** (появилась опора на опубликованную
натурную статистику класса и стандартные методы пуллинга; собственной
натурной статистики по-прежнему нет — дальше 3 без неё не поднять).
