## 1. GridLoss: многоузловой AC-расчёт установившегося режима (P1-5)

**Модуль:** `server/hydro_api/grid_powerflow_v9.py`

### Постановка

Двухузловая модель V8 не масштабировалась на реальную радиальную сеть Магаданской области (пос. Усть-Среднекан — пос. Синегорье — Магадан, десятки узлов 35–220 кВ). Реализован общий метод Ньютона—Рафсона в полярной форме для радиальных сетей:

- неизвестные `[Δθ; ΔV/V]` для всех PQ-узлов; балансирующий узел 0 с фиксированным `|V|`, `θ=0`;
- матрица узловых проводимостей Ybus (G + jB) из паспортных R, X ветвей (без ёмкостной проводимости — для 35–110 кВ на десятках км это допустимое приближение, см. ограничения);
- блоки якобиана H, N, M, L по стандартной полярной форме:
  - внедиагональные: H_ik = V_i V_k (G_ik sin θ_ik − B_ik cos θ_ik), N_ik = V_i V_k (G_ik cos θ_ik + B_ik sin θ_ik), M_ik = −N_ik, L_ik = H_ik;
  - диагональные: H_ii = −Q_i − B_ii V_i², N_ii = P_i + G_ii V_i², M_ii = P_i − G_ii V_i², L_ii = Q_i − B_ii V_i²;
- решение линейной системы — плотное гауссово исключение с частичным выбором главного элемента; вырожденный якобиан — ошибка `SINGULAR_JACOBIAN`, а не мусор на выходе;
- критерий сходимости: max |ΔP|, |ΔQ| < 1e-12 о.е.; несходимость за 100 итераций — `NR_NOT_CONVERGED`;
- валидация топологии: дерево (n−1 ветвей, единственный родитель, обход без циклов), сплошная нумерация узлов, запрет дублей нагрузок.

### Верификация

Эталон — распределительная сеть **IEEE 33-bus** (Baran & Wu, 1989, DOI 10.1109/61.19227; 12,66 кВ; 3715 кВт + 2300 квар):

| Метрика | Литература | Наш солвер | pandapower 3.5.6 |
|---|---|---|---|
| Vmin, о.е. | 0,9131 (узел 18) | 0,9130905 (узел 18) | 0,9130905 (узел 18) |
| Потери, кВт | 202,67 | 202,6771 | 202,6771 |
| Итерации | — | 5 | — |

Расхождение с pandapower: max |ΔV| = 4,8·10⁻¹¹ о.е., |ΔP_loss| = 1,5·10⁻¹¹ кВт — на уровне машинной точности итерационных критериев. Воспроизводится скриптом `scripts/benchmark_grid_ieee33_v9.py`; квитанция с SHA-256 — `artifacts_v9/grid_ieee33_benchmark_v9.json`.

### Ограничения (честно)

- Только радиальные сети (топология Магаданской энергосистемы это допускает; кольцевые 110 кВ — за пределами).
- Нет шунтов/ёмкостей линий, нет трансформаторов с РПН, нет генерации кроме slack.
- Нет расчёта несимметрии и токов КЗ — это отдельная задача (P2).

## 2. HydroForecast: русловая трансформация Маскингама—Кунджа (P0-3)

**Модуль:** `server/hydro_api/routing_v9.py`

### Постановка

Прогноз притока в створ ГЭС без русловой трансформации бесполезен для каскада: приток в верхний створ ≠ приток в нижний во времени. Реализован классический Маскингам и вывод параметров из гидравлики канала (Cunge, 1969; параметризация Понса):

- `S = K·(X·I + (1−X)·O)`; рекуррент `O_t = C0·I_t + C1·I_{t−1} + C2·O_{t−1}` с `C0+C1+C2 = 1` (проверяется с допуском 1e-9);
- **fail-closed на классической области неотрицательных коэффициентов** `2KX ≤ dt ≤ 2K(1−X)`: вместо молчаливого отрицательного C0 — ошибка с вычисленным допустимым диапазоном dt;
- Маскингам—Кундж: `K = dx/c_k`, `X = ½(1 − Q/(B·S0·c_k·dx))`, глубина и скорость из Мэннинга для широкого канала (`c_k = 5V/3`);
- контроль баланса массы по трапециям с поправкой на запас воды в створе на конец гидрографа.

### Верификация (тесты `tests_v9/test_routing_v9.py`)

1. Вырожденный случай `dt = 2KX = K` (X=0,5) → чистая задержка `O_t = I_{t−1}` — точно.
2. Гауссов паводок: затухание пика, положительный лаг, относительная ошибка баланса массы < 1e-3.
3. Постоянный приток проходит без изменений (стационарность).
4. Отказ на отрицательных коэффициентах, отрицательном притоке, dt вне полосы М—К.

### Ограничения

- Линейная модель: K и X постоянны по расходу. Для паводков с выходом на пойму нужна нелинейная параметризация K(Q) — следующий шаг (P1).
- Не верифицировано на натурных гидрографах Колымы — это работа под досье `docs/V9_OPEN_DATA_DOSSIER_RU.md` (GRDC/R-ArcticNET).

## 3. HydroForecast: вероятностная верификация (P0-2)

**Модуль:** `server/hydro_api/probabilistic_verification_v9.py`

### Постановка

Точечные метрики (NSE/KGE по WMO-1364) не оценивают качество вероятностного прогноза. Добавлен стандартный набор (Gneiting & Raftery, 2007, JASA 102:359–378; Hersbach, 2000, MWR 128:2636–2648):

- **CRPS** ансамбля в энергетической форме: `CRPS = mean|x_i − y| − (1/2m²)·ΣΣ|x_i − x_j|` — строгий proper score; для m=1 вырождается в MAE;
- **PIT** — значение эмпирической CDF ансамбля в наблюдении (вариант Херсбаха с половинным весом совпадений); у калиброванного прогноза PIT ~ U(0,1);
- **покрытие интервалов** — эмпирическое vs номинальное для центрального (1−α)-интервала по перцентилям ансамбля;
- **rank histogram** — ранг наблюдения среди членов (m+1 корзин); плоскость = калиброванность, U-форма = недооценка дисперсии, купол = переоценка.

### Верификация

1. Аналитический эталон: `CRPS({0,1}, 0.5) = 0.25` — точно; идеальный детерминированный прогноз → 0.
2. Обмениваемые выборки (наблюдение из того же распределения, m=19): покрытие 90%-интервала сходится к теоретическому конечно-ансамблевому значению `(k_hi−k_lo)/(m+1) ≈ 0,857`, а не к наивным 0,90 — тест это фиксирует; PIT mean ≈ 0,500.
3. Недодисперсионный ансамбль (σ_анс = σ_ист/10): покрытие < 0,5, U-образная гистограмма — диагностика работает.
4. Отказы: пустой ансамбль, NaN/Inf, рассинхрон длин.

### Ограничения

- PIT-тест однородности (Андерсон—Дарлинг) не реализован — нужен при n ≥ 100 натурных случаях (после GRDC).
- CRPS без декомпозиции reliability/resolution/uncertainty (Hersbach) — добавить при появлении климатологии станции.

## 4. TurbineReliability: ISO 20816 + Weibull MLE + экономика обслуживания (P1-4)

**Модуль:** `server/hydro_api/turbine_reliability_v9.py` — первый кодовый модуль TurbineReliability (зрелость 0 → 2).

### 4.1. Зоны вибрации ISO 20816-5

Классификация A/B/C/D с **обязательными пользовательскими границами**: модуль принципиально не содержит «типовых» чисел, т.к. границы зон в ISO 20816-5:2018 зависят от типа машины, точки измерения и жёсткости опоры, а сам стандарт платный. Ввод границ из несертифицированного источника = ложная сертификация — поэтому fail-closed. Проверяется строгая монотонность границ A/B < B/C < C/D.

### 4.2. Weibull 2-параметрический MLE с правым цензурированием

`f(t) = (β/η)(t/η)^(β−1)·exp(−(t/η)^β)`. Профильный метод: при фиксированном β масштаб имеет замкнутый вид `η̂(β) = (Σt^β/r)^(1/β)`, а score-уравнение по β сводится к скалярному

`g(β) = 1/β + mean_e(ln t) − Σ t^β ln t / Σ t^β = 0`,

где `g'(β) = −1/β² − Var_w(ln t) ≤ 0` (Коши—Буняковский) — g строго убывает, корень единствен, Ньютон с бисекционной страховкой сходится гарантированно (4–6 итераций). Веса `t^β` считаются в лог-домене — устойчиво к overflow при любых β.

**Верификация на синтетике с известной правдой:** β=2,0 (изнашивание), β=1,0 (пуассоновские отказы), β=0,7 (приработка) восстанавливаются с относительной ошибкой < 15 % на n=200–500, в т.ч. с 12–25 % цензурирования.

### 4.3. Экономика обслуживания

`E[C] = P(T < horizon)·Loss + C_prev`; решение PREVENTIVE при `E[C_run] > C_prev`. **Пока `calibrated_on_field_failures = False` решение принудительно HOLD** — вероятность отказа из некалиброванной модели не может оправдать остановку агрегата.
