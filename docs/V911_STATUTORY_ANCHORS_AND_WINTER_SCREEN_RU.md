# HydroKontur 360 — V9.11: нормативные якоря и проверка зимней реализуемости

**Исследование, 21–22.11.2026** · **Статус: необходимая предварительная проверка, НЕ юридическая или инженерная сертификация.** Ветка является продолжением научного V9.10 Draft PR #36; `main` и production не меняются.

## 1. Наиболее важное обнаружение: запрет нетурбинного зимнего сброса

[Правила Росводресурсов, приказ от 07.07.2025 №174](https://sudact.ru/law/prikaz-rosvodresursov-ot-07072025-n-174-ob/prikaz/), зарегистрирован Минюстом 01.08.2025 за №83126:

- [Раздел VIII, пункт 52](https://sudact.ru/law/prikaz-rosvodresursov-ot-07072025-n-174-ob/pravila-ispolzovaniia-vodnykh-resursov-kolymskogo/viii/): в период **устойчивых отрицательных температур** (обычно октябрь–апрель) эксплуатационный водосброс Колымского и глубинный водосброс Усть-Среднеканского гидроузлов использовать не допускается; сброс в нижние бьефы осуществляется через гидроагрегаты. Это **условное нормативное ограничение**, для окончательной оценки необходимо подтвердить температурное условие, возможность другого механизма вывода, реальный объектный режим и предусмотренные действующими нормами исключения.
- Раздел VIII, п.44–49: режим определяется по [диспетчерским графикам зон](https://sudact.ru/law/prikaz-rosvodresursov-ot-07072025-n-174-ob/pravila-ispolzovaniia-vodnykh-resursov-kolymskogo/viii/), а не только суммой ГВт·ч и полезным объёмом. Планирование загрузки ГЭС связано с эксплуатационными и энергосистемными условиями; текущие две эвристики этого не выполняют.
- Раздел VIII, п.47: интервал регулирования **месяц** для октября–апреля, **декада** для мая–сентября с возможностью сокращения в особых условиях. Месячный расчёт V9 не означает автоматического соответствия данным правилам.
- [Раздел VI, п.26–30, 35](https://sudact.ru/law/prikaz-rosvodresursov-ot-07072025-n-174-ob/pravila-ispolzovaniia-vodnykh-resursov-kolymskogo/vi/): нижняя граница УМО весь год, сезонные верхние ограничения НПУ/ФПУ; допустимая скорость снижения уровня 1 м/сутки для обеих ступеней и повышения 1 м/сутки для нижнего водохранилища; разрешённый интервал **нетто-напора**, соответствующий объекту. Это необходимые ограничения, но не полноценное описание допустимых диспетчерских режимов.

**Результат для прежнего исследования:** в V9.8–V9.9 формировались модельные `ust_spill_km3` и `kolyma_spill_km3` — объёмы, пропускаемые мимо турбин. В частности, при исходном *thermal-first* номинальном сценарии 2023 модель фиксировала **2,651339 км³** зимнего нижнего холостого сброса. С учётом п.52 нельзя трактовать соответствующий результат как проверенный реальный/нормативно реализуемый режим. При неизвестных фактических температурах результат получает **потенциальный конфликт**; при документально подтверждённом устойчивом холоде и прочих равных — конфликт с указанным пунктом. Значение ноль по холостому сбросу **не** даёт автоматический нормативный PASS.

## 2. Версионированные нормативные якоря

В [реестре V9.11](../data/reference/kolyma_cascade_rules_2025_v911.json) занесены значения из публично доступных разделов I, V, VI и VIII. Источник — переписанный опубликованный **вторичный** текст: оригинальные байты официально опубликованного документа с SHA-256 не получены и не подтверждены независимым правообладателем. Поэтому реестр **не** имеет статус аттестованного операционного источника.

| Показатель | Колымское водохранилище | Усть-Среднеканское |
| --- | ---: | ---: |
| УМО, м БС | 431,06 | 278,00 |
| НПУ, м БС | 450,56 | 290,00 |
| ФПУ, м БС | 456,66 | 292,30 |
| Полная ёмкость при УМО, км³ | 7,838 | 2,863 |
| Полная ёмкость при НПУ, км³ | 15,077 | 5,436 |
| Полная ёмкость при ФПУ, км³ | 17,961 | 6,085 |
| Полезный объём, км³ | **7,239** | **2,573** |
| Объём форсировки, км³ | 2,884 | 0,649 |
| Допустимый нетто-напор, м | 90–119 | 38–61 |
| Санитарный сброс в зоне I, м³/с | 100 | 70 |

В исходной публикации [раздела V](https://sudact.ru/law/prikaz-rosvodresursov-ot-07072025-n-174-ob/pravila-ispolzovaniia-vodnykh-resursov-kolymskogo/v/) в строке мёртвого объёма замечена размерностная неоднозначность (`км²` вместо `км³`), хотя физический смысл и арифметика указанных объёмов требуют `км³`. Исправление размерности в машиночитаемом реестре отмечено как **подлежащее сверке с аутентичным официальным оригиналом**, не как подтверждённое издателем исправление.

Для Колымского водохранилища по [разделу I, п.3](https://sudact.ru/law/prikaz-rosvodresursov-ot-07072025-n-174-ob/pravila-ispolzovaniia-vodnykh-resursov-kolymskogo/i/) отметки ОС на **0,94 м выше БС**. Нижняя ступень не получает выдуманного преобразования ОС.

**Контроль водного объёма:**
```text
Колымское:       15.077 - 7.838 = 7.239 км³
Усть-Среднек.:    5.436 - 2.863 = 2.573 км³
Колымское ФПУ:   17.961 - 15.077 = 2.884 км³
Усть ФПУ:         6.085 - 5.436 = 0.649 км³
```

## 3. Новая проблема с боковым притоком

Из [раздела V, п.24](https://sudact.ru/law/prikaz-rosvodresursov-ot-07072025-n-174-ob/pravila-ispolzovaniia-vodnykh-resursov-kolymskogo/v/): средние многолетние компоненты водного баланса нижней ступени `15,193 км³/год + 9,820 км³/год = 25,013 км³/год`. В прежней ссылочной базе V9.7 использована **4,5 км³/год** боковой приточности. Разность `9,820−4,5=5,320 км³/год`.

**Нельзя просто заменить 4,5 на 9,82**: отличаются потенциальные гидрологические периоды, створы и методики. Число 9,82 относится к многолетней нормативной балансовой таблице, а 4,5 — к вторичному источнику прежнего кода. Это сигнал к **source/grain/basin reconciliation**, а не готовая замена параметра. Ни одно новое фактическое подключение не подтверждено.

## 4. Инженерный контракт предварительной проверки

- `server/hydro_api/normative_stage_v911.py`: строгие `Decimal` проверки объёмов и уровней, единиц и систем высот; проверки календарных верхних и нижних пределов, скоростей изменения уровня, опубликованного интервала нетто-напора и условного зимнего нетурбинного сброса.
- **Отсутствующие кривые не подменяются прямыми:** промежуточный `V(z)` не восстанавливается линейной интерполяцией лишь по УМО/НПУ/ФПУ. Для любой иной отметки — строгий отказ `V911_NON_ANCHOR_CURVE_NOT_DIGITIZED`.
- Физическая формула `P=ρgQHη` допускается лишь как **синтетическая проверка единиц и границ** с явным вводом `H`, не как вычисление реального напора или реально доступной мощности.
- `scripts/magadan_normative_screen_v911.py`: независимо рассматривает все **216** вариантов V9.9 (из агрегатов нижнего холостого сброса), но **не** заявляет законность даже нулевого сброса. V9.10 хранит только **4** полных эталонных траектории из 384: только эти траектории просматриваются помесячно; для остальных полный помесячный нормативный скрининг **недоступен**.
- Никаких автоматических команд диспетчеризации, оценки реальных MW, LOLE/EENS, инвестиционных выводов и промышленной интеграции. Реальные кривые, полномочия, метеорологическое условие и N−1 требуют независимого подтверждения.

**Важнейшее архитектурное решение:** исследовательская нормативная проверка не меняет и не ретуширует **V9.8/V9.9/V9.10**. Все три оригинальных артефакта воспроизводятся побайтно. Новое исследование показывает, почему их результатам нельзя приписывать физическую и юридическую допустимость без дополнительных входов.

## 4.1 Исполненный скрининг исторических расчётов

**Проверяемый артефакт:** [V9.11 normative screen](../artifacts_v9/magadan_normative_screen_v911.json).

На специальном [GitHub Actions #44951006892](https://github.com/PetrFedin/magadan/actions/runs/44951006892) фактически исполнено **359/359 тестов, 0 SKIP** (промежуточный исходный SHA `3cdcd46af215f9c7891b5afb6fa9ba1060a43f74`), повторно проверены и побайтно воспроизведены V9.8/V9.9/V9.10 и дважды — новый нормативный отчёт. Затем дополнительно введены проверки источников **уже сохранённого** отчёта и цифровой природы температурных флагов; их проверка на финальном SHA является отдельным обязательным шагом, её нельзя считать успешной задним числом.

| Выборка | Выявлено положительных нетурбинных сбросов | Можно считать законным режимом? |
| --- | ---: | --- |
| V9.9 thermal-first, 216 зимних вариантов | **213/216** содержат нижний холостой сброс | Нет; потенциальный конфликт с п.52 при подтверждённом устойчивом холоде |
| V9.9 hydro-first, 216 зимних вариантов | **0/216** по сохранённой нижней сводке | Нет; нет полного набора допустимых зон и условий |
| V9.10: 4 полных эталонных сценария, 3 варианта каждый, 6 месяцев | **0/72** месячных проверок обнаружили нетурбинный сброс | Нет; это только четыре сценария и условная модель |
| V9.10: остальные **380** комбинаций | Нет полных помесячных данных для данного gate | **Не проверено** |

Последняя колонка не означает подтверждённое юридическое нарушение 213 сценариев: в моделях не сохранено фактическое подтверждение устойчивых отрицательных температур. В реальных условиях потребуются конкретные погодные даты и квалификация типа водосброса.

**Принципиальное последствие:** V9.9 установила, что hydro-first оставляет меньше воды на конец зимы, а V9.10 показала 30/192 пар с большим недоотпуском при hydro-first в стрессовых условиях. Теперь выяснилось также, что thermal-first часто формирует **условный водосброс мимо турбин**, требующий отдельной нормативной проверки. Следовательно, выбор реальной стратегии по простому ранжированию этих двух старых вариантов *некорректен*. Необходима единая физически допустимая многопериодная модель каскада.

**Источник чисел** — скрипт `scripts/magadan_normative_screen_v911.py`, репозиторные JSON V9.9/V9.10 и отдельный исходный реестр; квитанция `payload_sha256 = 3ac43663ba1910b7dfb63746e445f3f6605b344a9ec43b2b92d326e22fd2ec23`, хеш сохранённого файла `2fd3e4e60912914825114ec9a33210586e81c6afdf664e470efbc214f4157f63`.


## 5. Допуск к V9.12 и более поздним расчётам

1. Получить аутентичный полный официальный акт №174 и зафиксировать официальные оригинальные байты и юридическую ревизию; проверить права на машиночитаемую републикацию и внешнюю инженерную экспертизу.
2. Извлечь полностью, с проверенной системой высот и контурами применимости: [приложение №8 — Колымское `V(z)`](https://www.consultant.ru/document/cons_doc_LAW_511518/91bb682e8cf8343579697f747662b0f8a8bae9fc/), [№9 — Усть-Среднеканское `V(z)`](https://www.consultant.ru/document/cons_doc_LAW_511518/eb87fccd241dc115530300966e0365ddb43923eb/), №10/11 — характеристики нижних бьефов, №12/13 — зональные диспетчерские графики. Проверить монотонность, плотность опорных точек, допустимость экстраполяции, диапазоны и дату редакции.
3. Добавить реальные допустимые расходы по зонам, агрегатные характеристики, ограничения оборудования, охлаждение и зимнее состояние водосбросов, сохранение воды по часам с калиброванной задержкой. Учитывать многолетний график и обязательный остаток на конец сезона.
4. Отдельно вести гидрометеорологические доказательства устойчиво отрицательных температур для применения п.52, а не использовать месяц года как достаточную замену факту.
5. Провести независимый бэктест на согласованных связанных гидрологических годах, затем — почасовой adequacy при согласованных ремонтах и отказах блоков, независимой топологии и N−1. Вероятности LOLE/EENS только при обоснованных весах.
