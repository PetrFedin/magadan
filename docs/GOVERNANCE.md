# Регламент GitHub

Целевая структура: `server/hydro_api/`, `server/tests*/`, `server/migrations/`, `server/ui/`, `v6-client/`, `scripts/`, `docs/`, `research/`, `artifacts_v*/`.

Выпуск только из отдельной `feature/*` ветки и Draft PR после сверки файлов и отсутствия секретов. `main` не допускается в production до GREEN CI на одном SHA, реального нативного PostgreSQL, независимого ревью, RLS/SSO/WORM и объектной приёмки. Исторические миграции неизменны; каждое изменение схемы отдельным номером. Суммирование эффекта между модулями — только после атомарной проверенной версии глобального реестра выгод.

Каждый release имеет `manifest SHA256`, матрицу требований и фактические результаты QA, ограничения, миграции, инструкции воспроизведения и отдельный статус `PRODUCTION HOLD` при отсутствии промышленных доказательств.
