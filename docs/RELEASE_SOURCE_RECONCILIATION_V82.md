## Фактическая сверка Git-дерева и локального архива

Метод: вычислить для каждого из 496 путей исходной локальной сборки Git blob SHA-1 (`sha1('blob ' + len(bytes) + NUL + bytes)`) и сравнить с содержимым рекурсивного GitHub Git Trees API на указанном SHA.

| Показатель | Факт |
| --- | ---: |
| Контрольных файлов в манифесте архива | 496 |
| Точное совпадение Git blob по содержимому | **495** |
| Отсутствующих файлов | **0** |
| Намеренных несовпадений | **1: README.md** |
| Обрезка ответа GitHub Tree API | **false** |

**README.md** отличается намеренно: в GitHub это актуализированный проектный путеводитель с информацией о PR, структуре и статусе, тогда как ZIP V8.2 сохраняет README из предыдущего локального базиса. Исходные модули, расчёты, тесты и SQL не имеют таких расхождений. Архивный манифест нельзя использовать как доказательство полного **побайтового** совпадения GitHub HEAD без учёта README — зафиксированное расхождение не скрывается.

GitHub blob SHA-1 проверяет равенство загруженных байтов с подготовленной версией, но **не подтверждает авторство, независимую подпись оригинального ZIP или доверенное происхождение реальных гидрологических данных**.

## Лабораторные тесты — не промышленные доказательства

**Локально:** 321 Python PASS, 1 SKIP (нативный PostgreSQL), 63 JS PASS, 20 синтетических сценариев. Браузерный тест реально запускался, но Chromium вернул `ERR_BLOCKED_BY_ADMINISTRATOR`. Инженерная независимая верификация, разрешённые магаданские данные, PostgreSQL 17/RLS, SSO/MFA, внешний WORM и финансовая аттестация — **не выполнены**.

**GitHub Actions:** статусы должны проверяться на конкретном SHA Draft PR V8.2. Зелёный результат тестов импортёра, исторической V8.0 или другого SHA нельзя переносить на этот релиз.

## Следующее решение

V8.2 оставить отдельным Draft PR для проверки; `main` не трогать. Публиковать NPV, фактические эффекты или прогнозы для реальных ГЭС только после появления разрешённых данных, независимого расчёта/эксперта и полного выполнения допусков.
