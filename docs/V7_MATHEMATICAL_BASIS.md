# AC двухузловая модель — проверяемая математическая основа V7

Трёхфазная **симметричная** сеть с единственным идеальным отправляющим узлом, одним последовательным линейным сопротивлением `Z=R+jX` на фазу и постоянной PQ-нагрузкой. Все данные синтетические.

Для фазных комплексных величин:

`V_s = V_r + Z I`, `S_φ = V_r I*`, `S = 3 S_φ`, `V_s,φ = V_s,LL / sqrt(3)`.

**Численный путь**: решаем систему двух вещественных уравнений для реальной и мнимой частей `V_r` с помощью `scipy.optimize.root`. Отдельно вычисляем `I=conj(S_φ/V_r)`, комплексную отправляемую мощность и потери `S_loss = 3 |I|² Z`.

**Независимый алгебраический путь**: после перехода к `y = |V_r|²` получаем

`y² - a y + b = 0`, где

`a = |V_s|² - 2 Re(Z conj(S_φ))`, `b = |Z|² |S_φ|²`.

Высоковольтная ветвь решения `y = (a + sqrt(a² - 4b))/2` (при положительном дискриминанте и `a>0`). Сравниваем `sqrt(y)` с модулем численного `V_r`, проверяем невязку узловых уравнений и сохранение активной мощности.

**Учебные входы:** 20 кВ линейного напряжения, 5 МВт и 2 Мвар нагрузки, `R=0,3 Ом`, `X=0,4 Ом`, период 100 часов. Два алгоритма дают: потери 0,022004055 МВт, или 2,200405534 МВт·ч за 100 ч, полученное линейное напряжение 19,884206378 кВ, невязка активной мощности практически равна нулю на заданной точности.
