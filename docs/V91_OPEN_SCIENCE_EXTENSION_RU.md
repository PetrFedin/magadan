## 1. Опорные открытые параметры (data/reference/)

Файл `data/reference/kolyma_magadan_open_sources.json` вводит класс
`OPEN-PUBLISHED-REFERENCE` — третий класс данных рядом с `SYNTHETIC-*` и
(отсутствующими у проекта) натурными `FIELD-*`. Правила:

- каждое числовое поле несёт `source_ref` в реестр источников (URL, издатель, дата обращения);
- расхождения источников не усредняются молча — фиксируются в `notes_ru`
  (пример: табличный прогноз максимума нагрузки СО ЕЭС 564→574 МВт на 2025–2030
  при текстовой оценке 546 МВт к 2030 г.);
- отсутствующий параметр — `null`, не экспертная оценка;
- `usable_for_production_decisions: false`.

Ключевые якоря (все — из файла, со ссылками на источники):

- **Колымская ГЭС**: 900 МВт (5×180), напор 108 м, НПУ 451,5 м, полная/полезная
  ёмкость 15,08/7,24 км³, проектная выработка 3,325 млрд кВт·ч, факт 2024 г. — 2,002 млрд кВт·ч.
- **Усть-Среднеканская ГЭС**: 570 МВт (4×142,5), напор 58,4 м, НПУ 290 м, 5,4/2,57 км³;
  строительство завершено в декабре 2024 г.
- **Энергосистема** (СО ЕЭС, СиПР 2025–2030): изолированная; установленная 1790 МВт
  (ГЭС 1470 = 900+570 — перекрёстная проверка сходится; ТЭС 320); максимум нагрузки
  460 МВт (2023), драйвер — золотодобыча (~44% потребления, 2018).
- **Гидрология**: R-ArcticNET ст. 5858 (Усть-Среднекан, 99 400 км², 1936–1988);
  рост среднегодового стока устья на 27,7% в 2010–2020 к базе 1971–2000; снижение
  летнего стока с середины 1990-х из-за роста деятельного слоя мерзлоты
  (MDPI Remote Sensing 2021); проекция +50±25% стока к концу века.

## 2. Degree-day снеготаяние (`snowmelt_v9.py`, HydroForecast)

Классическая схема (HBV; Hock 2003): линейное разделение фаз осадков в полосе
2h вокруг порога, таяние `M = DDF·max(0, T−T_melt)`, ведёрко жидкой влаги с
удерживающей способностью `f_hold·SWE`, обратное замерзание при отрицательных
температурах. Инвариант: баланс воды по прогону с допуском 1e-9; нарушение —
`ArithmeticError`, а не предупреждение. Параметры по умолчанию — литературный
стартовый диапазон (`params_source: SYNTHETIC-LITERATURE-DEFAULT`), калибровки по
створам Колымы нет ⇒ `decision: HOLD`. Назначение — драйвер притока под
ERA5-Land после загрузки данных владельцем (см. `scripts/fetch_open_hydro_data.py`).

## 3. Генерационная адекватность (`adequacy_v9.py`, issue #18)

COPT рекуррентной свёрткой двоичных состояний агрегатов (Billinton & Allan);
по хронологическому ряду нагрузки — LOLE [ч] и EENS [МВт·ч]; критерий N−1
(установленная минус крупнейший агрегат против пика). Тесты включают точное
совпадение свёртки четырёх одинаковых агрегатов с биномиальным распределением и
дымовой расчёт в масштабе системы (1470 МВт ГЭС + 320 МВт ТЭС, пик 460 МВт).
FOR агрегатов — допущение, не статистика отказов ⇒ `for_assumption=True`,
`decision: HOLD`.

## 4. Декомпозиция CRPS (`crps_decomposition_v9.py`, HydroForecast)

Пороговая форма CRPS (Hersbach 2000, eq. 5): `CRPS = ∫ BS(F(z), 1{y≤z}) dz`.
Для ансамбля из m членов F(z) принимает ровно m+1 значений, поэтому
Мёрфи-декомпозиция (1973) двойки Бриера в каждой точке z точна:
`BS = REL − RES + UNC`. Интегрирование выполняется точно по кусочно-постоянным
интервалам между изломами. Рантайм-инвариант: `REL − RES + UNC == mean_crps`
с допуском 1e-9, проверяется в каждом вызове. Предельные случаи в тестах:
климатологический прогноз ⇒ RES = 0; идеальный детерминированный ⇒ CRPS = 0,
RES = UNC; смещённый ансамбль ⇒ рост REL на порядок.

## 5. Теплосеть (`heatnet_v9.py`, HeatNet Economics 1→2)

Тепловая часть — точное экспоненциальное остывание вдоль изолированной трубы
при доминирующем сопротивлении изоляции `R' = ln(D_ins/D)/(2πλ)`; гидравлика —
Дарси—Вейсбах, Свами—Джейн для турбулентного режима с независимой перекрёстной
проверкой Хааландом (расхождение < 3% в тесте), 64/Re для ламинарного.
Переходная зона 2300<Re<4000 честно помечается `transitional` и берётся худший
из граничных f. Ограничения модели (занижение потерь из-за неучтённых стенки,
конвекции и грунта; табличная вязкость) перечислены в `model_limitations`
результата — не скрыты в документации.
