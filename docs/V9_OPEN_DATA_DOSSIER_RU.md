# Досье открытых гидрометеорологических данных для Колымского каскада (V9)

**Назначение:** перевод HydroForecast с синтетики на реальные данные — шаг 5 шкалы зрелости (REAL-DATA). Досье фиксирует, какие открытые источники покрывают бассейн Колымы, что именно скачивать, на каких условиях и как данные вводятся в репозиторий, не нарушая культуру provenance (карантин источников V8.9).

**Принцип:** никаких «примерно релевантных» данных. Каждый источник проверен на фактическое покрытие створа Колымской/Усть-Среднеканской ГЭС.

## 2. Источники: верифицированное покрытие

### 2.1. R-ArcticNET — основной кандидат (открытый, без регистрации)

- **Что:** месячный (и для 139 российских рек — суточный) сток арктических рек; R-ArcticNET v4.0 / ArcticRIMS (Water Systems Analysis Group, Univ. of New Hampshire).
- **Покрытие Колымы:** есть, верифицировано постранично 16.11.2026:
  - **Kolyma at Ust'-Srednekan** — код Росгидромета 1010, R-ArcticNet ID 5858; 62.43° N, 152.30° E; водосбор 99 400 км²; месячный архив **1936-01 – 1988-12**; страница `https://rims.unh.edu/data/station/station.cgi?station=5858` — створ непосредственно у каскада;
  - апстрим **Kolyma at Orotuk** (ID 5855) и даунстрим (ID 5951) — для калибровки русловой трансформации;
  - региональный файл: AllData → регион 6 «Anadyr and Kolyma Basins» (`https://www.r-arcticnet.sr.unh.edu/v4.0/AllData/index.html`), там же суточный архив по российским рекам (16 МБ).
- **Ограничение:** ряд обрывается ~1988 г. (суточные поднаборы — начало 2000-х). Годится для калибровки/верификации модели на историческом климате, НЕ для операционного прогноза.
- **Лицензия:** научное использование с цитированием (Lammers et al., 2001, JGR 106:3321–3334).

### 2.2. GRDC — основной для современного ряда (требуется заявка)

- **Что:** Global Runoff Data Centre (Bundesanstalt für Gewässerkunde, Кобленц) — мировой эталон архива стока; колымские створы в каталоге есть (в т.ч. суточные ряды по заявке).
- **Доступ:** бесплатно для научных целей по заявке с описанием проекта; сроки — недели.
- **Действие:** заявку подаёт владелец проекта (нельзя автоматизировать). Рекомендуется запросить суточный ряд Усть-Среднекан + Колымское, максимальная длина.
- **Лицензия:** GRDC Terms of Use — запрет перепубликации сырых данных; в репозиторий вносятся только производные (параметры моделей, метрики) + ссылка на заявку.

### 2.3. GSIM (PANGAEA) — метаданные и индексы

- Global Streamflow Indices and Metadata archive (Do et al., 2018, ESSD): индексы стока + метаданные водосборов; колымские станции присутствуют через вклад R-ArcticNET/GRDC.
- Доступ: открыто через PANGAEA (DOI-раздача). Полезен для площадей водосбора и характеристик бассейна.

### 2.4. ArcticGRO — свежие ежегодные обновления

- arcticgreatrivers.org/discharge/ — сток шести крупнейших арктических рек, включая Колыму (Среднеколымск, код 1801; 361 000 км²; с 1936 г., с пропусками 2019–2020, закрытыми корреляцией с Колымским). Данные свободны «for any purpose» (по заявлению проекта), раздача со страницы discharge/.
- Ограничение: замыкающий створ, помесячная/годовая агрегация — для валидации многолетних объёмов, не для внутригодовой динамики каскада.

### 2.5. Реанализ и осадки (для модели снег-сток)

- **ERA5-Land** (Copernicus CDS): 0.1°, почасовые/суточные T, осадки, снег с 1950 г. Доступ по бесплатному API-ключу CDS (регистрация владельцем). Это будущий драйвер degree-day/snowmelt-блока.
- **GPM IMERG** (NASA): спутниковые осадки 0.1°, 30 мин, с 2000 г. Открыто (регистрация NASA Earthdata).

### 2.6. Исключено после проверки

- **Caravan** (Kratzert et al., 2023): НЕ покрывает Россию — набор собран из стран с открытыми национальными архивами; для Колымы бесполезен. Зафиксировано, чтобы не возвращаться.

## 3. Порядок ввода данных (протокол карантина)

1. Скачивание — только скриптом `scripts/fetch_open_hydro_data.py` (локально у владельца): он фиксирует URL, дату скачивания, SHA-256 каждого файла в манифест.
2. Сырые данные R-ArcticNET (свободная лицензия) можно коммитить в `data/open/` с манифестом. Данные GRDC — НЕ коммитить (условия лицензии); коммитятся только производные.
3. Каждый импорт проходит картину источника: `source_id` вида `OPEN-RARCTICNET-1010-*` + запись в реестр источников; синтетический флаг снимается только после сверки контрольных сумм и витрины пропусков.
4. Первый натурный прогон HydroForecast: rolling-origin backtest на ряде Усть-Среднекан 1936–1988 с отчётом CRPS/PIT (модуль `probabilistic_verification_v9`) — и только после этого зрелость 5.

## 4. Ближайшие действия (по приоритету)

1. Владелец: запустить `scripts/fetch_open_hydro_data.py` локально → PR с `data/open/` + манифест.
2. Владелец: подать заявку в GRDC (форма на grdc.bafg.de; пример формулировки — ниже).
3. После получения: калибровка K/X Маскингама между створами Колымская→Усть-Среднекан на исторических паводках.

### Формулировка для заявки GRDC (черновик)

> Scientific project "HydroKontur 360 — Magadan": non-commercial open-source research on runoff forecasting and cascade hydropower economics for the Kolyma River basin (Magadan Oblast, Russia). Requested: daily and monthly discharge time series, maximum available length, for Kolyma at Ust'-Srednekan and Kolymskoye stations. Data will not be redistributed; only derived model parameters and verification metrics will be published.
