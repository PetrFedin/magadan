# V9.3 — EMOS-калибровка климатологического ансамбля на реальном ряде

Дата: 2026-11-16. Продолжение [V9.2](V92_REAL_DATA_BACKTEST_RU.md). Пакет отвечает
на дефицит, который показали сами данные V9.2: климатологический ансамбль на
створе 5858 дал скилл +0,437 против persistence, но покрытие 80%-интервала
0,614 при номинале 0,80 — недооценка неопределённости. Классический инструмент —
EMOS (Ensemble Model Output Statistics, Gneiting et al. 2005, MWR 133,
doi:10.1175/MWR2904.1): диагностическая калибровка предиктивного распределения
по прошлым парам «ансамбль-наблюдение».

## 1. Метод (`server/hydro_api/emos_v9.py`)

Модель — NGR для обмениваемых членов в лог-шкале (сток положителен и
правоскошен):

```
log Q ~ N(a + b·mean(log ens), σ²),   σ² = c + d·var(log ens),  c,d > 0
```

Предиктивный ансамбль — 20 равновероятных квантилей логнормали (уровни
(i+0.5)/20): фиксированный размер сохраняет совместимость с rank histogram и
декомпозицией CRPS. Подгонка минимизирует средний CRPS по обучающим парам
собственным детерминированным Nelder-Mead (одинаковый вход → бит-в-бит
одинаковый результат; несходимость — fail-closed `EMOS_FIT_NOT_CONVERGED`).

Две постановки цели, верифицируемые раздельно:

- `objective="log"` — классический EMOS: замкнутая форма CRPS нормали в
  лог-шкале;
- `objective="original_scale"` — CRPS квантильного ансамбля в м³/с:
  оптимизируется ровно метрика верификации.

## 2. Причинность (двойная)

Для случая (Y, m): предиктивный ансамбль — климатология 20 лет < Y; EMOS
обучается на парах (y, m), y ∈ [Y−20, Y−1], где ансамбль пары y — климатология
20 лет < y. Утечки будущего нет по построению. Цена: оценочный период EMOS —
1973–2000 (первые 20 лет уходят на обучение калибровки), 333 случая, 666
подгонок, все сошлись (максимум 1062 итерации при лимите 4000).

## 4. Честное чтение — частично отрицательный результат

1. **Калибровка положения исправлена**: PIT mean 0,657 → 0,482 (сырое окно
   систематически занижало сток — отстающий тренд; EMOS это убрал).
2. **Покрытие улучшено, но не до номинала**: лучший вариант 0,628 против
   0,80. Постобработка масштабирует дисперсию, но не может добавить
   информацию о тренде — дефицит покрытия на этом ряде структурный
   (нестационарность), а не только дисперсионный.
3. **Цена калибровки — острота**: CRPS original_scale 255,3 против 247,2 у
   сырой климатологии (−3%); классический EMOS в лог-шкале ухудшает CRPS
   исходной шкалы заметно (−21%) — цель в лог-шкале не совпадает с метрикой
   верификации, это и мотивировало вторую постановку.
4. Вывод для дорожной карты: дисперсионной калибровки недостаточно; нужен
   **драйвер притока** (degree-day snowmelt V9.1 под ERA5-Land) и/или
   тренд-адаптивная климатология. EMOS остаётся полезным финальным слоем
   поверх физически информированного ансамбля.

Зрелость HydroForecast **не повышается** (остаётся 3): постобработка базовой
климатологии — не модель выше базовой. `production_ready=False`, HOLD — без
изменений.
