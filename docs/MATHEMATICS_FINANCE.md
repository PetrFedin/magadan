# Математика и финансовая логика

Электросети: `V_i=V_parent−(R+jX)I_i`; активные потери `P_loss=3|I|²R`. Валидировать узловой KCL, границы напряжения/тока, время наблюдений, модельный период. `E_saved=(P_loss,base−P_loss,alt)*hours*cycles*1000*retention`. Не экстраполировать отсутствующие часы автоматически.

Экономика: `Gross_y=Σ_w(E_saved_yw × avoided_cost_yw)`, `CF_y,s = Gross_y × factor_s − OPEX_y − CAPEX_WBS_y`, `NPV_s=Σ_y CF_y,s/(1+r)^(y−y0)`. CAPEX только из одной WBS; первая выгода после ввода; отрицательный NPV не скрывать. Не приравнивать условную стоимость энергии к утверждённому тарифу.

ГЭС: `V(t+1)=V(t)+(Qin−Qout)Δt`, `P=ρgQHη`, обязательны кривые уровня/объёма и правила использования водохранилищ. Теплосети: `Qdot=m_dot*c_p*(T_supply−T_return)`. Диагностическая аномалия турбины не равна подтверждённой вероятности отказа.

M&V: контрфактическая модель обучается только на информации, доступной до даты ввода; проверяется на историческом holdout, учитывает нагрузку и температуру. Ни один модельный результат без реальной метрологии/независимого заключения не признаётся фактической экономией.
