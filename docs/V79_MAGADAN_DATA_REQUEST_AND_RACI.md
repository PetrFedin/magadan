## 2. Minimum data delivery manifest

- Organization and person authorizing release, signature/date and precisely defined permitted use.
- Classification and required confidentiality, physical hosting, allowed recipients, retention and deletion policies.
- Date of technical state and topology revision; station voltage/base/rated output, hydraulic coordinates and GIS projection where relevant.
- For each record: event time, available-to-planner time, unit, measurement method, data quality, source ID, revision, calibration references and uncertainty.
- Completeness report (source points, expected intervals, actual intervals, missing/late/overlap counts, repairs and source-change logs).
- Independent reference calculation method and person competent to sign a technical opinion.
- Distinct engineering, economic and public/regional benefit methodology; no automatic equation between reduced grid loss and tariff/revenue changes.

## 4. Engineering-to-finance evidence checklist

`Asset -> measurements -> reviewed topology -> baseline model -> candidate action -> engineering constraints -> independent calculation -> approved estimate -> WBS/CBS -> schedule -> legal permits -> finance scenarios -> authorized decision -> commissioned installation -> verified M&V -> recognized effect`.

Block on any missing critical edge. `Research study` and `real monetary benefit` are different record types with separate signature requirements.

## 5. Field milestones

- G0: signed legal owner and access conditions.

- G6: regulatory and planning permissions determination.
