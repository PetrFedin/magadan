# Архитектура HydroKontur 360

Шесть продуктов:

| Модуль | Модель | Связь |
|---|---|---|
| HydroForecast | гидрологические прогнозы, backtesting, неопределённость | CascadeEconomics |
| CascadeEconomics | водный баланс, гидромощность, режимные ограничения | HydroCAPEX |
| TurbineReliability | аномалии, диагностика, ремонт | HydroCAPEX |
| GridLoss Planner | AC-поток, напряжения, I²R, варианты инвестиций | HydroCAPEX, M&V |
| HeatNet Economics | тепло/гидравлика, потери | HydroCAPEX |
| HydroCAPEX | WBS/CBS, CAPEX/OPEX, NPV, этапы проекта | инженерное и финансовое досье |

Сквозной процесс: исходный источник → право на данные → версионированный расчёт → независимая инженерная проверка → WBS и экономика → полномочное согласование → строительно-монтажная реализация → измеренный результат → аудит. Лабораторный расчёт не имеет прав на физическое управление. PostgreSQL 17 RLS, внешнее WORM, корпоративный SSO и настоящие данные объектов не приняты.
