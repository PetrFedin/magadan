# ГИДРОКОНТУР 360 — МАГАДАН · V8.3.2

**Доказательная лабораторная инженерная версия. Данные только синтетические.**

В предыдущей V8.3.1 выявлены два ошибки на искусственных кривых: midpoint-оценка суточной энергии не всегда совпадает с интегралом по кусочно-линейной кривой уровня и проверка только midpoint-мощности пропускает пиковое превышение.

В V8.3.2:

1. Для постоянных расхода через турбину, потерь напора, КПД и суточного линейного изменения запасов реализован **точный интеграл** по ломаной storage→upstream elevation.
2. Теоретический мгновенный пик мощности проверяется на обоих концах линейной траектории хранения воды. Если пик превышает предел станции, энергия становится `null`, статус `PHYSICAL_SCREEN_FAILED`, признанной генерации или денежных эффектов нет.
3. В API добавлены диагностические `head_at_start_m`, `head_at_end_m`, `max_instantaneous_theoretical_power_mw`, `energy_integration_method`; в интерфейсе явно показывается ошибка мощности.
4. Создана независимая программная проверка 256 искусственных кривых через 4096 временных точек, негативные тесты пересечения узлов кривой, начала и конца суток, нулевого расхода, исключения экстраполяции.

Ограничения: нет внутрисуточной динамики притока, работы отдельных гидроагрегатов, измеренной η(Q,H), ветрового нагонного эффекта, гидравлической модели, реальных объектов и разрешений на источники, независимой инженерной экспертизы. Статус **PRODUCTION HOLD**.
