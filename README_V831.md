## Изменения

- Начальный объём на начало будущих суток и **полный предыдущий суточный сброс** явно объявлены как условные значения из будущего относительно момента выпуска гидропрогноза (D 10:00 UTC). Прогноз расхода проверен на отсутствие использования ещё недоступных наблюдений, но **вся связка с ГЭС остаётся условной** до появления плана/оценки этих будущих значений.
- Существующий чистый временной перенос воды отдельно пересчитан на почасовой сетке: **438** случаев, случайные расходы с фиксированным seed, с отдельным учётом воды в пути. Это *вторая программная реализация той же упрощённой модели*, не внешний решатель гидравлики.
- Добавлены 6 негативных/размерностных тестов на плотность, нулевой Q, отрицательный напор, сочетание нулевого общего баланса с недопустимым режимом и ложное представление будущих данных как известного факта.
- Полная локальная Python-регрессия после обновления: **363 PASS, 3 SKIP**; JS **63 PASS**. Результаты реально выполненных групп записаны в `artifacts_v83/TEST_REPORT_V831.md` и `artifacts_v83/acceptance_summary_v831.json`.
- Дополнен ручной GitHub Actions сценарий лабораторных проверок маршрутизации. Его выполнение на GitHub зависит от доступности runner; статусы локального теста нельзя объявлять GitHub CI PASS.
