# ГИДРОКОНТУР 360 - МАГАДАН
## V7.1 RC1: серверная архитектура и проверки

**Статус: кандидат для контролируемой лаборатории. Промышленный допуск не получен.**

Продолжение исходников V7, а не заявление о подключении к системам РусГидро. Реальные данные электросети Магаданской области не получены. Независимый инженер не подписывал заключение.

## Что сделано

Разработан адаптер корпоративного входа OIDC Authorization Code + PKCE S256. Идентификация связывается с заранее разрешенной парой issuer + subject; адрес почты и роли из внешнего токена сами по себе прав не дают. В браузере используется случайная серверная сессия, а не токен провайдера. Добавлены проверки state, nonce, подписи, времени входа, CSRF и отзыва сессии.

Подготовлены миграции PostgreSQL, разделенные роли доступа, FORCE RLS, составные связи организации и объекта, контроль версий и запрет подмены контекста. Подписанный контекст ограничен транзакцией и текущей сессией. Сравнение с SQLite не считается проверкой RLS.

Создан отдельный приемник аудита. Квитанция связывает событие, его содержимое, версию объекта и срок хранения. Подпись Ed25519 проверяется экспортером. Для базы подготовлена дополнительная проверка HMAC с отдельным ключом, недоступным экспортеру. Режим LAB_FILE не является WORM.

Добавлено повторное выполнение электротехнического расчета с проверкой исходных данных, версии модели, кода и среды. Вторая реализация выполняет математическое сравнение. Это не заменяет заключение независимого специалиста.

## Содержимое пакета

server/hydro_api/identity.py - корпоративный протокол и сессии.

server/migrations/ - шесть последовательных миграций для новой отдельной базы.

server/hydro_api/audit_delivery.py - прием, подписанные квитанции и доставка аудита.

server/hydro_api/pg_security.py - подключение приложения под ограниченной ролью.

docs/ARCHITECTURE_V71.md - границы доверия, связи и правила отказов.

docs/RUNBOOK_V71.md - запуск и приемка. docs/MAGADAN_PILOT_V71.md - состав данных и допуска к испытаниям.

artifacts_v71/TEST_REPORT.md - фактические проверки и ограничения. Старые документы и снимки V6/V7 сохранены отдельно и не являются новой приемкой.

## Правила запуска

Инструкции в docs/RUNBOOK_V71.md используются только в новой изолированной базе с префиксом hydrokontur_v71_. Скрипт отказывается работать в непустой базе. Секреты создаются заново и не должны попадать в репозиторий. Настройки в .env.example - только образец.

Рабочие репозитории, производственные серверы и корпоративные данные не изменялись. Новый конвейер GitHub Actions находится только в локальном пакете; он не опубликован и не запущен.

## Условие следующего этапа

Сначала нужно выполнить миграции и нативные тесты на реальной изолированной PostgreSQL, затем проверить корпоративный вход и независимый архив. Только после этого допускается рассматривать импорт разрешенных данных объекта Магаданской области и подписание программы независимой инженерной приемки.
