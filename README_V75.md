Дата: **23 октября 2026 года**. **Статус: LAB PASS (в указанном объёме) / PRODUCTION HOLD**. Продолжение локальной V7.4, без изменений GitHub или промышленных серверов. ## Главное изменение

До V7.5 шесть исследовательских программ были объединены преимущественно семантическими связями. V7.5 добавляет **две численные проверяемые передачи** с API, авторизацией, контролем источников и неизменяемым сохраняемым результатом:

1. `HydroForecast → CascadeEconomics`: исторический прогнозный ряд притока м³/с с UTC, непрерывными шагами и явно заданным лагом подаётся в упрощённую двухступенчатую модель; фактические будущие наблюдения не подменяют прогноз. Учитываются предельные объёмы, расходы и мощность; нарушение не исправляется автоматически.
2. `TurbineReliability → Maintenance Alternatives`: диагностическое отклонение переводится в условные варианты инспекции/ремонта с материалами, трудом, северной логистикой, простоем, сроком поставки и стоимостными предпосылками. **Вероятность отказа и предотвращённый ущерб не выдумываются**; вариант автоматически не выбирается.

В обоих случаях источник должен принадлежать разрешённой организации, быть синтетическим, воспроизводимым и неизменённым. Результат имеет `industrial_approval_eligible=false`.

