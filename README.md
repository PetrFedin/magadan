# ГИДРОКОНТУР 360 — МАГАДАН

**V8.3 · инженерно-экономическая лабораторная платформа · SYNTHETIC RESEARCH ONLY**

**Границы:** энергетика Магаданской области и потенциальные исследовательские задачи группы «РусГидро». Упоминание компании не означает сотрудничества. Посторонние проекты, включая «Беринг», **не входят** в архитектуру и данные ГИДРОКОНТУР 360.

**Операционный статус:** локальный LAB PASS / PostgreSQL 17, корпоративная идентификация, WORM, гидравлическая экспертиза, данные владельца и production — **HOLD**. Никакого SCADA/дистанционного управления, выдачи команд на сброс, признания экономии и реального инвестиционного решения.

## Шесть компонентов и порядок

| Модуль | Содержание | Источник доказательств до промышленного применения |
| --- | --- | --- |
| HydroForecast | Суточный прогноз, rolling holdout, ошибки и диапазон неопределённости | Гидрологические измерения и независимый гидролог |
| CascadeEconomics | Водный баланс двух водохранилищ, запаздывание, уровни, КПД, условная энергия | Паспортные кривые, правила эксплуатации, гидравлика |
| TurbineReliability | Измерение аномалий и условные сценарии обслуживания | Размеченные события, подтверждённый журнал ремонтов |
| GridLoss Planner | AC-модель сети, напряжения и электрические потери | Реальная схема, измерения, внешний решатель |
| HeatNet Economics | Тепловой баланс и потери сети | Реальные температурные и расходные режимы |
| HydroCAPEX | WBS/CBS, планирование затрат, сценарии DCF/NPV | Сметы, цены, налогово-тарифная методика, фактическая M&V |

**Общая цепочка:** происхождение данных → права → математический расчёт → независимое подтверждение → сценарии → уникальный реестр эффекта → WBS/финансы → профессиональное решение → контроль факта.

## Код

- `server/hydro_api/` — математические модели, экономический контур, RBAC и HTTP API.
- `server/migrations/` — SQL-кандидаты 001–160; исполнение на PG17 требует отдельного протокола.
- `server/tests*` — независимые фикстуры, негативные тесты, лабораторная проверка ролей.
- `server/ui/` — лабораторная web-панель; V8.3 — раздел 15.
- `scripts/` — воспроизведение сценариев, проверочные утилиты.
- `artifacts_v*/` — артефакты и ограничения по версиям.
- `.github/workflows/` — отдельные контуры CI и нативной PG-приёмки.
- `v6-client/` — исторический клиент с 63 JavaScript-тестами.
