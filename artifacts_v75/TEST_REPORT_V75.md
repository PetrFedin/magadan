## Заблокированные либо не проводившиеся испытания

- Настоящий PostgreSQL 17 отсутствует. Запуск обязательного теста с `HYDRO_NATIVE_TESTS_REQUIRED=1` завершился кодом 2 на этапе collection и маркером `NATIVE_ACCEPTANCE_BLOCKED`. **Это не PASS и не промышленная проверка RLS.** Ранее подготовленная SQL-миграция 090 требует исполнения на изолированном стенде и конкурентных проверок.
- Корпоративный OIDC/MFA — не подключён. Синтетический IdP не равнозначен реальному.
- Внешнее защищённое WORM-хранилище с независимыми квитанциями — не подключено.
- Настоящий browser↔HTTP API E2E — не выполнен. Статический скриншот не считается успешным E2E.
- Реальные данные ГЭС, электросетей и теплосетей Магаданской области — не получены, договор на использование данных не подтверждён.
- Независимая инженерная верификация по исходным данным правообладателя, проектные решения, рабочие чертежи, промышленная смета, подтверждение финансового результата — не получены.

## Объём новых математических связей

**HydroForecast → Cascade:** передача *исторического прогнозного*, а не наблюдённого позднее расхода воды, строгих единиц м³/с, времени UTC, сценария и искусственной задержки. Проверяется баланс и нарушения упрощённых ограничений. Число 6992.568 МВт·ч в примере синтетическое и не соответствует данным Колымского каскада.

**TurbineReliability → Maintenance:** прозрачные варианты обследования и ремонта по явно заданным расходам и простоям. В демонстрации полные условные суммы 56000.00 ₽ и 272000.00 ₽. **Никакой оценённой вероятности отказа и автоматического выбора нет.**

**Сквозное досье:** дочерние расчёты привязаны к SHA конкретной версии родительской программы, повторно вычисляются и проверяются ролью аудитора; WBS пример на 1600000.00 ₽ не является сметой объекта.

## Принцип выпуска

Лабораторные проверки подтверждают техническую согласованность **на конкретных синтетических тестах**. Нельзя считать соответствие уровня ISO/GOST, полученную выгоду «РусГидро», безопасность для КИИ или промышленный допуск без независимой процедуры. Github и производственные серверы не изменены.

Следующий рубеж: отдельный PostgreSQL 17, нативные миграции 001–090 и RLS, IdP/MFA, WORM, браузерный E2E, разрешённый сетевой участок Магаданской области, независимая электротехническая/гидрологическая экспертиза.
