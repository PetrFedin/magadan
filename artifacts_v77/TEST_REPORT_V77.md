## Блокирующие тесты НЕ пройдены

1. PostgreSQL 17 native RLS: `HYDRO_NATIVE_TESTS_REQUIRED=1 ...` завершился кодом **2** и ошибкой `NATIVE_ACCEPTANCE_BLOCKED: dedicated PostgreSQL configuration is missing`. SQL-кандидат не исполнен.
2. pandapower: запуск внешнего адаптера остановился с `PANDAPOWER_NOT_INSTALLED`; реального внешнего результата нет.
3. Корпоративный OIDC/SSO с MFA на производственном провайдере не подключён.
4. WORM/Compliance Object Lock и независимая квитанция хранения на реальном провайдере не подтверждены.
5. Данные реальной сети Магаданской области, согласованная топология, калибровка и независимое инженерное заключение отсутствуют.
6. Полный браузерный E2E с аутентификацией не засчитан: проведена только статическая визуальная проверка.
7. Никаких разрешений на инвестиционное решение, строительство или управление энергообъектами не выдано.

## Точные ограничения доказательства

- Исходный тестовый «внешний ответ» создаётся из результата нашего первого решателя **только для проверки передачи данных**, что явно маркируется в JSON. Совпадение здесь не является независимым физическим тестированием.
- Внутренний nodal KCL cross-check и stress-suite проверяют согласованность математической реализации, не эталон для реальных сетей.
- Финансовые примеры синтетические, без подтверждения тарифов, цен и инженерных объёмов.
- Скриншоты получены статически без обращения к API; корректность браузерной бизнес-логики не подтверждается.
- Предыдущие манифесты сохранены исторически; текущий SHA-256-манифест выпущен отдельно и должен использоваться для проверки V7.7.
