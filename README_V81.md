# ГИДРОКОНТУР 360 — МАГАДАН · V8.1 (исследовательский кандидат)

**Предмет:** инженерная физика и экономика энергетики Магаданской области. Потенциальные прикладные задачи «РусГидро» **не означают** действующих договорных отношений, промышленного доступа или признанных результатов. Посторонние проекты (включая «Беринг») не входят в согласованную архитектуру.

## Зачем V8.1

В лабораторной V8 обнаружен потенциальный race condition: транзакция добавления графа физической измерительной границы и транзакция создания первого экономического эффекта не использовали общий per-org lock. Новая **добавочная** миграция `160_boundary_claim_serialization_v81.sql` связывает их одной транзакционной advisory-блокировкой. Она консервативно принимает только `READ COMMITTED`, сохраняя первоначальную миграцию 150 неизменной.

## Устройство и связь

HydroForecast → CascadeEconomics; TurbineReliability, GridLoss Planner и HeatNet Economics → технические альтернативы → физический boundary graph → единый реестр синтетических эффектов → HydroCAPEX (WBS/CBS, CAPEX/OPEX, NPV) → независимый аудит/измерения. **Ни одна техническая оценка автоматически не становится фактической денежной экономией.**

## Воспроизведение лабораторных проверок

```bash
python -m pip install -r server/requirements.txt
PYTHONPATH=server python -m pytest -q server/tests_v81/test_sql_graph_serialization_v81.py
PYTHONPATH=server python -m pytest -q server/tests_v8 server/tests_v79
(cd v6-client && npm test)
```

Конкретные результаты в `artifacts_v81/TEST_REPORT_V81.md`: **289 Python PASS, 63 JS PASS, 1 нативный модуль PostgreSQL SKIP** по раздельным группам. Только локальная лабораторная проверка. Изолированная PostgreSQL 17, SQL race E2E, RLS, corporate SSO/MFA, WORM, независимая электротехническая сверка и реальная стоимость эффекта **не приняты**.

Нативный SQL-тест `server/tests_v81/test_pg_graph_freeze_native_v81.py` требует отдельной конфигурации `HYDRO_NATIVE_CONFIG` и настоящей PostgreSQL 17; статус нельзя повышать без его выполнения. Он сам по себе не доказывает все реальные сценарии регистрации эффекта.
