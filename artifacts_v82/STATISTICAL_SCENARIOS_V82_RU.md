# HydroForecast V8.2 — статистический отчёт по лабораторным сценариям

**Источник:** `scripts/reproduce_v82.py` + точный синтетический ряд. **Никаких данных реальных ГЭС или гидропостов Магаданской области.** Дата выпуска отчёта: 2026-11-01. Все показатели получены выполнением кода, в рублях и МВт·ч расчётов нет.

В каждой строке: 168 суточных наблюдений; 84 ранняя история + 28 выбор модели + 28 калибровка + 28 независимая временная оценка. Номинальная полоса 90%, **эмпирическое** покрытие может отличаться. Режимный сдвиг искусственно добавлен только к последним 28 значениям — расчёт намеренно не способен «знать» его заранее.

## Пример интерпретации: h=2 суток

- В исходном синтетическом режиме: MAE **6.361132 м³/с**, RMSE **8.105325 м³/с**. Номинал полосы 90%, фактически **82.14%**: 23 из 28 значений внутри.
- При искусственном сдвиге на +65 м³/с: MAE **10.005494 м³/с**, RMSE **17.394822 м³/с**, фактическое покрытие **75.00%**: 21 из 28.
- Относительный рост MAE = `100 × (MAE_shift / MAE_baseline − 1)` = **57.29%**. Рост RMSE **114.61%**. Изменение покрытия **-7.14 процентного пункта**.
- Отбор выбрал модель **persistence**. На независимом holdout она не лучше простого `persistence` (skill = 0.0%). Это **недостаточная модель для прямого принятия решений**. Отбор/подгонка модели не исправляет неизвестную смену физического режима.
- Lag-1 корреляция ошибок базового holdout **0.359506**, что сигнализирует о возможной серийной зависимости и несоответствии простым предпосылкам интервального метода; **не** является тестом значимости корреляции.
