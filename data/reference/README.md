# data/reference — опорные открытые параметры

Опорные (якорные) значения из **открытых опубликованных источников** для калибровки
порядков величин синтетических сценариев платформы ГИДРОКОНТУР 360 — МАГАДАН.

## Принципы provenance (fail-closed)

1. `data_class: OPEN-PUBLISHED-REFERENCE` — это **не** натурные измерения и **не** первичная
   телеметрия. Класс отделён от `SYNTHETIC-*` (синтетика) и от любых будущих `FIELD-*`
   (натурные данные владельца актива, которых у проекта нет).
2. Каждое числовое поле несёт `source_ref` → запись в `sources` с URL, издателем и датой обращения.
3. При расхождении источников значение **не усредняется молча** — расхождение фиксируется
   в `notes_ru`, приоритет: официальный документ > отраслевой справочник > энциклопедия.
4. Отсутствующий в открытых источниках параметр = `null`, а не экспертная оценка.
5. `usable_for_production_decisions: false` — инвестиционные и эксплуатационные решения
   требуют первичных данных владельца актива.

## Файлы

- `kolyma_magadan_open_sources.json` — каскад Колымских ГЭС, энергосистема Магаданской области,
  тарифы, климат Магадана, гидрология Колымы (R-ArcticNET, рецензируемые статьи).

Модули `server/hydro_api/*_v9.py` читают эти данные только через явную загрузку файла;
провал загрузки или валидации => отказ обслуживания сигнатуры (fail-closed), а не подмена дефолтом.
